# Panthiya — live app

**Open it:** https://malingaprabhath7-maker.github.io/panthiya/

Panthiya (පන්තිය) is a web app for Sri Lankan tuition teachers: students, QR attendance, monthly fees with WhatsApp reminders, paper marks, notices, private pages for parents and a public class page with a chatbot. Sinhala and English, works offline. Try the demo class without an account.

This repository holds only the built website; the source code is private.
